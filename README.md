# Hanzhang Shen — personal website

A static personal academic website for GitHub Pages.

## Pages
- `index.html`: About, research interests, and news
- `academic.html`: academic activities, research and editorial experience
- `writing.html`: selected writing
- `recents.html`: recent observations, plans, and notes
- `assets/style.css`: responsive styling
- `assets/portrait.jpg`: supplied portrait, displayed with CSS cropping

## Publish
Create the public repository `hanzhangshen/hanzhangshen.github.io` and upload these files to its main branch. In Settings → Pages, choose Deploy from a branch, main, / (root). The expected URL is https://hanzhangshen.github.io.

## Preview
Run `python3 -m http.server 8765` from this directory and open http://localhost:8765. No build or dependencies are required.
